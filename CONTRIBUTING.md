# Contributing

This is a personal page. What I am glad to get:

- a broken link, a typo or a wrong credit;
- something that is hard to read or to reach with a keyboard or screen reader;
- the glass misbehaving on your device (say which browser and graphics card).

Open an issue, or a pull request for small fixes. Run `node check.mjs` first.

The page has no build step and no dependencies, and I would like to keep it so.
